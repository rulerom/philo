# Whaler：个性作为事件过滤器

Whaler 是第一个无需形而上学即可看清架构角色的实践案例。

```text
market -> level-v3 press -> 8-lane VSB tape
       -> Decima personality -> rare pattern event
       -> context/risk director -> execution or skip
```

市场产生不可逆的交易序列。Press 把它映射为归一化的 motion、range energy、tempo、买卖压力、mass、absorption 与 imbalance。

baker 构造液压个性：积累压力、释放压力、保留 lock 并发出事件的分支。

Decima 经历 tape。每个 ACTIVE 图块听同一帧，不同 signed matrix 积分不同关系。只有多段历史在一个器官内对齐时，才出现稀有信号。

director 根据 position、context 与 risk 决定是否允许动作。

输入频率不等于决定频率。数百万消息可能只产生少量事件，沉默往往是正确结果。

Whaler 不证明 Decima 万能。它证明了一件更小但重要的事：该架构可以在真实噪声环境中成为事件 sensor。
