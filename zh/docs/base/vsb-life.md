# 共享环境的八条弦

VSB 是八条共享 Level16 线。它并不声称世界只由八个值构成，而是选择对某个个性重要的八种投影。

```text
raw environment -> normalization -> 8 x Level16 -> VSB tape
```

改变线路语义、归一化或时间边界，会让同一 `.d8p` 生活在另一个世界。

每个 ACTIVE 图块收到相同帧。差异来自 signed 权重、积累历史、区间、decay 与许可图位置。

这里液压类比是准确的：一个 manifold 把八种压力提供给所有腔室，而各腔室的几何决定响应。

市场 press 可以把 motion、range energy、tempo、买卖压力、mass、absorption 与 imbalance 映射为归一化线路。这些意义属于 press，而不是 Decima。

八条线带来纪律，但充分性必须通过独立历史验证，不能由数字八本身证明。
