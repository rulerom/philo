# 反应区间

当 signed accumulator 进入以下范围时，图块锁存：

```text
thr_lo <= thr_cur <= thr_hi
```

这是工程反应窗口。上下界并不自动意味着“噪声”与“外来攻击”；其语义属于 baker 和具体器官。

单阈值只能表达“足够多”。区间可以分开积累不足、目标组合、溢出或另一种 regime。

Decay 也很重要：状态可能从过载下降进入区间并产生 FIRE。因此区间描述局部动力学的一段 phase，而不是单帧的静态阈值。

锁存后不会加入新 `delta`，但 decay 继续。离开区间或失去激活许可后，图块 unlock。

只有保留这套机制后，哲学上的“边界”类比才有意义。
