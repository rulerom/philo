# Граф допуска вместо маршрутизатора

Старое слово «эстафета» легко понять неверно: будто тайл передаёт свой числовой выход соседу. В v3 этого нет.

## Что действительно распространяется

Locked-предок разрешает локальному потомку стать ACTIVE на следующем такте. Потомок читает **новый общий VSB-кадр** и применяет собственные веса.

```text
locked parent
  -> permission edge
  -> ACTIVE child
  -> child reads common VSB
```

Это граф причинного допуска, а не сеть доставки пакетов.

## Почему это память порядка

Потомок не может начать свою часть реакции, пока предок не признал более раннюю фазу истории. Так локальная ветвь задаёт грамматику:

```text
сначала A
затем, пока A удерживается, проверить B
затем разрешить C
```

Данные A не текут в B. Связь состоит в том, что A открыл B возможность слушать среду.

## Схлоп

Когда lock предка исчезает, ветвь теряет разрешение и неактивные тайлы очищают runtime-состояние. Поэтому топология описывает не только распространение внимания, но и забывание.

Граф строит пекарь. Decima только детерминированно исполняет его над общей лентой.
