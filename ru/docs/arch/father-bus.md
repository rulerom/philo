# Общая шина и локальное разрешение

Метафора «отца, который открывает шину соседям» не соответствует runtime v3. Её заменяет более точное разделение.

## Три механизма

| Механизм | Функция |
| --- | --- |
| Общая `VSB_INGRESS16` | Один входной кадр для всех ACTIVE-тайлов |
| Локальные рёбра | Передача разрешения от locked-предка потомку |
| `BUS16` | Выходная сумма вкладов разрешённых BUS_W-тайлов |

`BUS_R` является историческим именем флага. Он не означает чтение BUS16: тайл с `BUS_R` просто является seed графа ACTIVE.

## Гидравлическая схема

Полезная аналогия — не семейный совет, а коллектор:

```text
8 общих давлений VSB
  -> множество локальных камер
  -> защёлки открывают соседние контуры внимания
  -> выбранные камеры дают вклад в выходной коллектор BUS16
```

Вода входа не обязана последовательно течь через камеры. Общая среда действует на них одновременно; топология определяет, какие камеры открыты для реакции.

## Роль пекаря

Пекарь решает, где расположены корни, какие lock открывают продолжение и какие органы имеют право писать readout. Поэтому контроль не принадлежит особому «отцу»: он распределён по спроектированной топологии личности.
