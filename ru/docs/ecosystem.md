# Экосистема Rule-ROM

Philo описывает принципы, но проверка происходит в коде, артефактах и приложениях.

| Домен | Роль |
| --- | --- |
| [Rule-ROM](https://rulerom.com/ru/) | Реестр проектов и публикационных границ |
| [Decima-8](https://decima.rulerom.com/ru/) | Физика v3, runtime, формат `.d8p`, IDE и benchmark |
| [Bakery](https://bakery.rulerom.com/ru/) | Инструменты архитектора для сборки и аудита личности |
| [Whaler](https://whaler.rulerom.com/) | Первое прикладное семейство: рынок, событийный сенсор и торговый контур |
| [C-SAFE](https://c-safe.rulerom.com/ru/) | Верификация и аудит |
| [PKI](https://pki.rulerom.com/ru/) | Подписи и происхождение артефактов |

## Граница открытости

Проверяемый контракт не требует публикации всей интеллектуальной собственности. Формат, физика исполнения, хеши и метод проверки могут быть открыты, а конкретная пекарня, обучающие ленты и прикладные правила оставаться закрытыми.

Эта граница важна для личности: пользователь понимает, что именно исполняется и как проверить неизменность `.d8p`, не получая автоматически рецепт её создания.
